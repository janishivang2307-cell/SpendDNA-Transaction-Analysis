SpendDNA – Transaction Analysis
Project Overview
SpendDNA is a Python-based transaction analysis project that analyzes financial transaction data to identify spending patterns, trends, anomalies, and spending behavior archetypes.

Objectives
Clean and validate transaction data
Standardize transaction information
Extract and standardize vendors
Categorize transactions
Analyze monthly spending patterns
Analyze time-of-day spending behavior
Detect unusual spending transactions
Identify spending archetypes
Generate an executive financial report
Features
Feature 1 – Data Cleaning
Cleaning and validation of raw transaction data.

Feature 2 – Vendor Extraction
Extraction and standardization of vendors from transaction descriptions.

Feature 3 – Category Classification
Classification of transactions into meaningful spending categories.

Feature 4 – Spending Overview
Analysis of credits, debits, categories, and vendors.

Feature 5 – Monthly Spending Trends
Analysis of spending patterns across different months and categories.

Feature 6 – Time-of-Day Analysis
Analysis of spending behavior according to transaction time.

Feature 7 – Anomaly Detection
Detection of unusual transactions using category-wise z-scores.

Feature 8 – Spending Archetypes
Identification of spending behavior using predefined quantitative rules.

Key Results
1,310 transactions analyzed
38 unique vendors identified
37 anomalous transactions detected
2.84% anomaly percentage
2 spending archetypes identified
Identified Archetypes
The Shopaholic
The YOLO Spender
